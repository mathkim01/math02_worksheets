진리집합을 알아봐요

한 활동씩 해 보세요. 정답을 맞히면 다음 활동이 열립니다.

6x가 있는 문장을 봐요

x < 4에서 숫자가 들어갈 자리를 나타내는 문자는 무엇인가요?

x에 어떤 숫자를 넣는지에 따라 문장이 참 또는 거짓이 될 수 있어요.

7한 값을 넣어 봐요

x < 4에 x = 3을 넣으면 3 < 4가 됩니다. 참일까요, 거짓일까요?

8여러 값을 확인해요

x < 4를 확인해요. 각 칸에서 참 또는 거짓을 고르세요.

x에 넣는 수문장참 / 거짓
11 < 4
33 < 4
44 < 4

9참이 되는 값을 찾아요

전체집합은 U = {1, 2, 3, 4, 5, 6}이에요.

전체집합에 있는 수 중에서 x < 4가 참이 되는 숫자를 작은 수부터 쉼표로 써 보세요.

10진리집합을 알아봐요

문장을 참으로 만드는 값을 모은 집합을 진리집합이라고 합니다.

아래 단어 카드에서 진, 리, 집, 합을 차례로 찾아 눌러 보세요.

진리집합을 찾아봐요

전체집합에 있는 수 중에서 문장을 참으로 만드는 수만 골라 보세요. 다 푼 뒤 정답을 열어 확인해요.

예제 1

U = {1, 2, 3, 4, 5, 6}

x < 3

진리집합:

정답 보기

{1, 2}

예제 2

U = {1, 2, 3, 4, 5, 6}

x는 짝수이다.

진리집합:

정답 보기

{2, 4, 6}

예제 3

U = {1, 2, 3, 4, 5, 6}

x > 4

진리집합:

정답 보기

{5, 6}
