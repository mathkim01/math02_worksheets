4. 이런 모임을 ‘집합’이라고 해요

같은 기준으로 모은 것을 집합이라고 합니다.

예)

따라 써 보세요.

5. 집합 안에 있는 것은 ‘원소’예요

집합 안에 들어 있는 하나하나를 원소라고 합니다.

과일의 집합

사과바나나포도

사과는 과일 집합의 원소입니다.

바나나는 과일 집합의 원소입니다.

포도는 과일 집합의 원소입니다.

맞으면 ○, 아니면 × 하세요.

1. 사과는 과일의 집합에 들어 있습니다.

2. 강아지는 과일의 집합에 들어 있습니다.

6. 집합은 { } 안에 써요

집합은 중괄호 { } 안에 씁니다.

과일의 집합

{사과, 바나나, 포도}

따라 써 보세요.

7. 하나씩 나누어 써요

예)
